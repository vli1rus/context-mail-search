# Контекст · поиск в почте
Пользователь может искать письмо своими словами, открыть подходящий фрагмент и сохранить письмо под своим ярлыком. Входящие, список результатов и чтение письма работают на компьютере и телефоне.

**Попробовать:** скачайте [START_CONTEXT.py](https://github.com/vli1rus/context-mail-search/raw/refs/heads/main/START_CONTEXT.py) и откройте в Python 3.11+. Встроены 30 демонстрационных писем. Для полного корпуса подключите данные организаторов. Порядок запуска на Windows и сервере описан в [RUN.md](RUN.md).

## Как устроен ящик
Поле `synthetic_user` определяет ящик каждого письма и запроса. В боковой панели перечислены идентификаторы из загруженного корпуса. «Настроить почту» позволяет дать ящику своё название, выбрать цвет, создать или переименовать ярлык и изменить оформление. В открытом письме можно назначить ярлык, изменить отображаемую тему или добавить письмо в избранное. Персональные настройки действуют в текущем браузере. Исходные темы и идентификаторы используются при поиске и скоринге.

## Что проверять в исходниках

| Файл | Назначение |
|---|---|
| mailsearch/data.py | Загрузка корпуса и проверка manifest.json |
| mailsearch/temporal.py | Разбор даты получения и относительных периодов |
| mailsearch/engine.py | Область видимости, BM25F, события, точные номера, слияние рангов и выбор фрагмента |
| mailsearch/server.py | HTTP API, просмотр писем, загрузка интерфейса и Server-Timing |
| mailsearch/evaluate.py | Recall, nDCG, MRR и экспорт списка doc_id для каждого query_id |
| web/ | HTML, стили и обработчики действий пользователя |
| tests/ | Проверки ранжирования, метрик, HTTP и пользовательских действий |
| build_standalone.py | Воспроизводимая сборка читаемого START_CONTEXT.py из исходников |

Стандартный режим работает локально на CPU. Он связывает разные формулировки ограниченным словарём почтовых событий, исправляет некоторые опечатки и учитывает реквизиты. Для явно заданной даты получения поиск отбирает доступные письма до ранжирования. Для запросов без такого ограничения дата события остаётся частью запроса. Опциональная ветка E5 требует отдельных весов и зависимостей.

## Измерения
На 99 публичных запросах организаторов nDCG@5 равен 0,4206 для BM25F, 0,8873 для BM25F с разбором даты и 0,9021 для нового поиска. Подробные результаты, ограничения и команды приведены в [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md). Материалы для защиты находятся в [DEMO_3_MIN.md](DEMO_3_MIN.md).
