# Проверка версии Почты
## Качество на публичном наборе VK
16 376 писем, 99 запросов, 565 положительных оценок. SHA-256 исходного файла участников `2df885f77be8f8aa750b484439fc99dfc2a401fce53306160c03ad95cae0de03`. Загрузчик сверил четыре файла с manifest.json. Для каждого запроса заданы свой ящик и дата. Метрики усреднены по запросам. MRR-single рассчитан по 42 запросам с единственным ответом.

| Вариант | Recall@10 | nDCG@5 | MRR@5 | MRR-single@5 |
|---|---:|---:|---:|---:|
| BM25F | 0,5264 | 0,4206 | 0,4813 | 0,4552 |
| Предыдущая версия | 0,6024 | 0,5239 | 0,6071 | 0,6000 |
| BM25F с разбором даты и видимого ящика | 0,8507 | 0,8873 | 0,9419 | 0,9881 |
| Новая версия | 0,8708 | 0,9021 | 0,9520 | 0,9881 |

Ящики публичных запросов отсортированы по SHA-256 идентификатора. Каждая третья позиция начиная с первой отложена. На четырёх ящиках разработки 58 запросов, на трёх отложенных 41. На отложенной части nDCG@5 новой версии 0,9209, предыдущей 0,5175, BM25F с обработкой даты 0,8888. В сравнении с предыдущей версией 28 улучшений, 3 ухудшения, 10 равенств. В сравнении с сильным контролем на отложенной части улучшились два запроса, остальные дали тот же nDCG@5. Формулировки между ящиками могут повторяться. Основную часть прироста объясняет дата получения. Приватный результат определяют организаторы.

## Скорость и воспроизводимость
На полном корпусе проверено совпадение первых 10 идентификаторов с экспортом для 99 запросов. По три повтора дают 297 запросов на уровень параллелизма. p99 времени обработчика до готового JSON составил 313,092 мс при одном клиенте и 764,195 мс при четырёх. Первый запрос 23,626 мс, начальная загрузка и индексирование 16,59 с, пик рабочего набора процесса 291,2 МиБ. Измерение выполнено через MailHandler с HTTP-байтами в памяти. Полный сетевой p99 на 16 376 письмах требует отдельного прогона через TCP. Порог VK относится к серверному времени, профиль приватной нагрузки неизвестен.

В отдельной синтетической проверке на 240 запросах nDCG@5 новой версии 0,6493, предыдущей 0,5834, BM25F 0,6811. Там лексический baseline сильнее. Встроенные 30 писем служат демонстрации. Поиск в измерениях работал без E5 и внешних API.

## Проверки
- 18 тестов Python прошли в локальном окружении с NumPy. Опциональный тест векторного индекса использует тестовый энкодер.
- Для файла запуска проверяются сборка из исходников и совпадение с версией в Git.
- GitHub Actions запускает Chromium на двух ширинах экрана, выполняет поиск, открывает письмо, меняет настройки и проверяет сохранение после перезагрузки. Затем собирает Docker-образ и обращается к серверу по HTTP. Фактический статус каждого коммита виден в [Actions](https://github.com/vli1rus/context-mail-search/actions).
- Для повторения скоринга, экспорта и сетевого замера используйте [RUN.md](RUN.md). В папке benchmarks лежат результаты по запросам и измерения обработчика.
