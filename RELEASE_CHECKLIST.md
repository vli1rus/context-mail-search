# RELEASE_CHECKLIST.md

## Статус

**Кандидат зафиксирован. Допуск к сдаче заблокирован проверками ниже.**

Выбран последний стабильный локальный режим smart без E5. Он прошёл тесты, демо-скоринг и экспорт. На прошлом синтетическом validation лексический BM25F был сильнее smart, но официального парного прогона нет. Сохраняем испытанную продуктовую конфигурацию и режим «По словам» для сравнения. Веса модели не используются. Рабочий индекс строится при запуске из входного корпуса. В архиве нет предсобранного индекса и кэшей. Для запуска достаточно стандартной библиотеки Python.

Исходная папка без истории Git. Стабильный снимок импортирован в отдельный локальный репозиторий. Сравнение выполнено с предыдущим архивом `fpmi_mail_search.zip`, SHA-256 `d6b6445a832e7c95f21bb75d9a816754ecb81e93cd0d7a0d3568fc6bbbca2701`, и импортированным коммитом `3e102da00deb8e651b6912c4b8f7c2395419bb83`. Исходники движка, интерфейс, тесты и встроенный корпус сохранились. Из пакета исключены исследования, диагностические наборы, отчёты прежних экспериментов и декларация опциональных зависимостей E5. Опциональный адаптер из стабильного кода остался, режим запуска без `--model-dir`. Скорректированы инструкции запуска и сценарий показа. Новых функций нет.

## Команды проверки

Из корня распакованного кандидата на Windows:

~~~powershell
python -m venv --without-pip .venv
.venv/Scripts/python.exe -m unittest discover -s tests -v
.venv/Scripts/python.exe -m mailsearch.evaluate --demo --k 1 5 10 --repeat 20
.venv/Scripts/python.exe -m mailsearch.evaluate --demo --mode smart --export-k 10 --output demo_check.jsonl
node --check web/app.js
.venv/Scripts/python.exe -m mailsearch.server --demo
~~~

В браузере открыть `http://127.0.0.1:8765`. Нажать пример про перенос вылета. В «Поездках» на 21.11.2026 режим «По словам» показывает пустую выдачу. В режиме smart открыть первое письмо и сверить 18:40. Добавить письмо в подборку и проверить после обновления. Для серверного прогона использовать второй терминал:

~~~powershell
python -m mailsearch.loadtest --repeat 10 --workers 8
~~~

После получения официального архива. K=10 здесь служит диагностике. Параметры сдачи сверить с инструкцией организаторов.

~~~powershell
python -m mailsearch.evaluate --dataset mipt_mail_search_participants.zip --k 1 5 10
python -m mailsearch.evaluate --dataset mipt_mail_search_participants.zip --mode smart --export-k 10 --output submission.jsonl
python -m mailsearch.server --dataset mipt_mail_search_participants.zip
~~~

Для HTTP-бенчмарка на полученных запросах из второго терминала передать `--queries PATH/queries_dev.jsonl` в `mailsearch.loadtest`.
